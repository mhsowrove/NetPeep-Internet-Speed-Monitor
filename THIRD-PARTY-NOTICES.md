# Third-party components

The small Windows build redistributes Microsoft's Microsoft.Web.WebView2 SDK 1.0.4314.35 Core and WinForms managed assemblies and x64 WebView2 loader. Microsoft's `LICENSE.txt` and `NOTICE.txt` from that SDK are shipped beside the executable as `WebView2-SDK-LICENSE.txt` and `WebView2-SDK-NOTICE.txt`. The WebView2 runtime is provided and maintained separately by Microsoft and is not included in this app's installer or portable ZIP.

The shared Electron/macOS development build uses Electron, Chromium and electron-builder dependencies with their respective licenses. Electron's packaging includes its own license files. The original NetPeep code and network icon artwork are MIT licensed.

PayPal, bKash, Microsoft and operating-system product names identify their respective services or runtime dependencies. NetPeep is not affiliated with those providers and does not process payments.
